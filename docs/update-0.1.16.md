# Update to 0.1.16

This release adds an account selector to Transactions, alongside type, year and date filters. Transfers match both accounts. Clearing the account selection restores all accounts; changing any filter returns to the first page. Opening balances remain excluded from transaction history.

New Studio artwork replaces the tanuki with an original anime male creative wearing glasses. New profiles use warm paper and muted teal. Existing profiles keep their saved appearance; select Studio in Settings > Appearance to switch.

Windows now embeds its launcher icon inside the executable and uses it for the app window. Android includes adaptive and legacy launcher icons. A launcher may retain its cached icon briefly after an update.

Back up through Settings > Data, then install the matching release over the existing application. Do not uninstall Android or clear storage. Ledger schema remains 10 and user registry schema remains 2. Optional AI models are not bundled or removed by the update.

Windows packages are unsigned. Android packages retain the existing debug/test signing identity and are not Play Store releases. See [testing and releases](testing-and-release.md) for the validation and privacy workflow.

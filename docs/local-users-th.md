# ผู้ใช้และ Login ในเครื่อง

แต่ละผู้ใช้มีสมุดบัญชีแยกกัน เลือกผู้ใช้และใส่รหัสผ่านก่อนเข้าแอป เมนูด้านบนแสดงชื่อผู้ใช้ปัจจุบัน พร้อม **แก้ไขผู้ใช้** และ **สลับผู้ใช้ / ออกจากระบบ**

เมื่ออัปเกรดจากรุ่นเดิม แอปจะผูก `ledger.sqlite3` เดิมกับโปรไฟล์ **Lookhin** โดยไม่ย้ายหรือลบไฟล์ เลือก Lookhin แล้วตั้งชื่อและรหัสผ่านครั้งแรก ไม่มีรหัสผ่านกลางหรือรหัสผ่านสำเร็จรูป คนที่ใช้อุปกรณ์ตอนตั้งค่าครั้งแรกเป็นผู้กำหนดรหัสนี้

ชื่อผู้ใช้ 1–40 ตัวอักษร ตรวจชื่อซ้ำโดยไม่แยกตัวพิมพ์ใหญ่/เล็ก รหัสผ่านอย่างน้อย 8 ตัวอักษร สูงสุด 256 ไบต์ สามารถใช้ภาษาไทยได้ การแก้ชื่อ/รหัสผ่านต้องยืนยันรหัสผ่านปัจจุบัน เว้นรหัสใหม่ว่างเพื่อเปลี่ยนเฉพาะชื่อ

ระบบเก็บรหัสผ่านเป็น Argon2id พร้อม salt สุ่มต่อรหัส ไม่มีรหัสผ่าน plaintext ในฐานข้อมูล การลองผิดห้าครั้งจะพักการ Login ของผู้ใช้นั้น 30 วินาที สถานะพักคงอยู่เมื่อเปิดแอปใหม่ งานอ่าน/เขียนของ session เก่าถูกปฏิเสธหลังออกจากระบบหรือสลับผู้ใช้

นี่คือ Login ภายในเครื่อง ไม่มี Cloud account, sync, email recovery หรือช่องทางย้อนดูรหัสผ่านเดิม และไม่ใช่การเข้ารหัสไฟล์ SQLite ผู้ที่เข้าถึงไฟล์ผ่านบัญชีระบบปฏิบัติการยังสามารถอ่านข้อมูลได้ เก็บไฟล์สำรองของตัวเองไว้เพื่อย้ายข้อมูลเข้าผู้ใช้ใหม่หากจำรหัสผ่านไม่ได้

ไฟล์ในโฟลเดอร์ข้อมูล:

- `user-profiles.sqlite3`: รายชื่อผู้ใช้ แฮชรหัสผ่าน และสถานะพัก Login
- `ledger.sqlite3`: สมุดเดิมที่ผูกกับ Lookhin
- `ledger-<opaque UUID>.sqlite3`: สมุดของผู้ใช้ที่สร้างใหม่ ชื่อผู้ใช้ไม่ได้ถูกนำไปประกอบ path

ติดตั้งทับรุ่นเดิมใน Windows user หรือ Android package เดิมจะใช้โฟลเดอร์เดิม อย่าลบแอป/ล้าง storage หากยังไม่ได้ส่งออกข้อมูล ดู [คู่มือย้ายข้อมูล](data-transfer-th.md)

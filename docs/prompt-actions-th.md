# บันทึกด้วยข้อความ — Desktop verification 24 กันยายน 2026

เปิด **บันทึกด่วน → คำสั่งบันทึกทั้งหมด** เพื่อเลือกตัวอย่าง แก้ชื่อ/ยอดให้ตรง แล้วกดอ่านรายการ ตรวจรายละเอียด และยืนยัน ไม่มีคำสั่งใดเขียนฐานข้อมูลทันทีที่อ่านข้อความ

## คำสั่งที่รองรับ

| งาน | ตัวอย่าง |
| --- | --- |
| รายจ่าย | `จ่าย 80 จาก เงินสด หมวด อาหาร` |
| รายรับ | `รับ 400 เข้า กรุงไทย หมวด ฟรีแลนซ์` |
| โอน / ชำระเงินต้นบัตร | `โอน 1000 จาก กรุงไทย ไป บัตรเครดิต` |
| สร้างบัญชีพร้อมยอดเริ่มต้น | `เพิ่มบัญชี ชื่อ ออม ประเภท ธนาคาร ยอดเริ่มต้น 5000` |
| รายจ่ายประจำ / หนี้ผ่อนรายเดือน | `เพิ่มรายจ่ายประจำ ชื่อ ค่ารถ ยอด 4500 บาท ทุกวันที่ 5 จำนวนงวด 12 เริ่ม 2026-10 จาก เงินสด หมวด อื่นๆ` |

| ลบบัญชีและรายการที่เกี่ยวข้องถาวร | `ลบบัญชี ชื่อ ออม` |

คำสั่งเหล่านี้ใช้ได้โดยไม่ดาวน์โหลดโมเดล รูปแบบข้อความอิสระที่อยู่นอกคำสั่งยังมีขอบเขตตาม [LLM contract](local-llm-th.md) จึงไม่รับประกันว่าจะเข้าใจทุกสำนวน ใช้ตัวอย่างหรือแก้ช่องข้อมูลในหน้าตรวจได้ ระบบไม่เดาเมื่อระบุไม่ได้

- หลายคำสั่งใช้ขึ้นบรรทัดใหม่, `;`, `แล้วก็` หรือ `และ` ครั้งละไม่เกิน 8 คำสั่ง ข้อความไม่เกิน 1,000 ตัวอักษร
- ชื่อ/รายละเอียดที่มีคำเชื่อมหรือคำบอกช่อง เช่น `และ`, `ชื่อ`, `เรื่อง`, `ยอด` ให้ครอบด้วย `"..."` เช่น `ชื่อ "เอ และ บี"`
- บัญชี แผน และลูกหนี้ที่สร้างในคำสั่งก่อนหน้า ใช้ชื่อเดียวกันในคำสั่งถัดไปได้
- ยอดบาทต้องไม่เกิน 2 ตำแหน่งทศนิยม รองรับลูกน้ำหลักพัน วันที่/เดือนใช้ ค.ศ. รองรับวันนี้/เมื่อวาน ช่องวันที่รายการเริ่มที่วันนี้
- ช่องที่ขาดแสดงคำถามบนฟอร์ม กดตรวจได้โดยไม่ปล่อยปุ่ม disabled เฉย ๆ ชื่อไม่พบหรือกำกวมจะแจ้งให้แก้/เลือกจากข้อมูลจริง
- ถ้าชื่อลูกหนี้มีหลายเรื่องหนี้ ให้เลือกเรื่องหนี้ใน dropdown เช่นเดียวกับแผนชื่อซ้ำและรายการยอด/รายละเอียดซ้ำ
- “จ่ายงวด” เติมยอด/บัญชี/งวดค้างแรกจากแผนได้ ยอดหรือวันที่ที่ระบุเองจะคงเดิม ต้องตรวจอีกครั้งก่อนยืนยัน
- “ตั้งจำนวนงวด” ใช้จำนวนรวมตั้งแต่เริ่มแผน ไม่ใช่งวดที่เหลือ และห้ามตัดงวดที่มีประวัติการบันทึกแล้วออก
- การลบบัญชีแสดงจำนวนรายการและยอดก่อน–หลังของบัญชีคู่โอนก่อนยืนยัน บัญชีที่เกี่ยวกับเงินให้ยืมหรือรับชำระหนี้จะลบไม่ได้ เพื่อคงประวัติยอดลูกหนี้

## หลายงานในข้อความเดียว

```text
เพิ่มบัญชี ชื่อ เงินสด ประเภท เงินสด ยอดเริ่มต้น 5000
ให้สมชายยืม 3000 บาท จาก เงินสด เรื่อง คอมพิวเตอร์ จำนวนงวด 3 เก็บทุกวันที่ 5 เริ่ม 2026-10
สมชายคืนหนี้ 1000 บาท เข้า เงินสด ดอกเบี้ย 50 บาท
```

เมื่อทุกคำสั่งผ่านการตรวจแล้ว จึงยืนยันทั้งหมดใน transaction เดียว หากรายการท้ายผิดหรือเขียนฐานข้อมูลล้มเหลว จะไม่มีรายการก่อนหน้าค้างบางส่วน หากข้อมูลเปลี่ยนหลังหน้าตรวจจะต้องตรวจใหม่ การกดยืนยันซ้ำของชุดเดิมไม่สร้างยอดซ้ำ

## ลูกหนี้และงวด

บันทึกยอดเงินต้นที่ยังค้าง ชื่อลูกหนี้ เรื่องหนี้ วันตั้งยอด เดือนเริ่มเก็บ จำนวนงวดและวันเก็บเลือกกำหนดหรือไม่กำหนดได้ มีทั้งแบบฟอร์มในหน้าลูกหนี้และ prompt

หนี้ที่มีอยู่แล้วเพิ่มสินทรัพย์ลูกหนี้ยกมา ไม่เพิ่มเงินสดหรือรายรับใหม่ การให้ยืมเงินใหม่ย้ายสินทรัพย์จากเงินในบัญชีไปลูกหนี้ เงินต้นรับคืนย้ายกลับเป็นเงินในบัญชี ดอกเบี้ยเป็นรายรับแยก ไม่รวมเงินต้นรับคืนซ้ำในรายรับหรือ Flow rate

กำหนดงวดแล้วแบ่งเงินต้นเท่ากัน เศษสตางค์อยู่ในงวดสุดท้าย รับชำระบางส่วนได้ ตัดงวดเก่าก่อน เมื่อครบเงินต้นจะจบแม้เลือกไม่กำหนดจำนวนงวด วันที่ 29–31 ที่ไม่มีใช้วันสุดท้ายของเดือน คิดยอดเลยกำหนดเฉพาะหนี้ที่มีทั้งจำนวนงวดและวันเก็บ และไม่นับวันครบกำหนดวันนี้ว่าเลยกำหนด

หน้าภาพรวมและหน้าลูกหนี้แสดงเงินต้นทั้งหมด รับคืนแล้ว คงค้าง ส่วนที่เลยกำหนด และจำนวนเรื่องหนี้ตามสถานะ ไม่สมมติว่าจะรับคืนในอนาคตแล้วเพิ่มรายรับทันที ยกเลิกการรับชำระจะเปิดยอดหนี้และงวดเดิมกลับมา

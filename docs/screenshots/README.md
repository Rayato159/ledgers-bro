# App screenshots

These screenshots are captured from the packaged 0.1.16 application using a newly created **Studio Demo** profile. Every account, transaction and balance is fictional. No personal database, receipt, account export or production screenshot was used.

- `desktop-overview.png`: Windows overview, Studio light theme.
- `desktop-account-filter.png`: Windows transaction history filtered to Everyday Bank expenses.
- `android-accounts.png`: Android x86_64 emulator account summary, Studio light theme.

The mobile capture is from the Android APK, not a narrow desktop simulation. Private regression-test captures and test databases remain outside this directory.

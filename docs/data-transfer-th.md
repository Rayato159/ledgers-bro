# นำเข้า CSV และย้ายข้อมูลไปอีกเครื่อง

เปิด **ตั้งค่า → ข้อมูล** บน Windows หรือ Android

## CSV สำหรับนำเข้ารายการ

กด **เปิดไฟล์ตัวอย่าง** เพื่อดูไฟล์ในแอปทันที ไม่ต้องติดตั้ง Excel บนมือถือ กด **บันทึกไฟล์ตัวอย่าง** เพื่อเก็บไฟล์แล้วแก้ไข ข้อมูลในตัวอย่างเป็นข้อมูลสมมติ ไม่ใช่รายการของคุณ

รูปแบบต้องเป็น UTF-8 (มี BOM ได้), comma-separated, มีหัวคอลัมน์เรียงตามนี้:

```csv
format,external_id,date,kind,account,destination,amount,currency,category,note
ledgers-bro-v1,my-coffee-001,2026-09-25,expense,เงินสด,,30.00,THB,food,กาแฟ
```

- `format`: `ledgers-bro-v1` ทุกแถว
- `external_id`: รหัสเฉพาะของรายการ 1–100 ไบต์ ต้องไม่ซ้ำกันในไฟล์หรือต่างไฟล์ ใช้รหัสเดิมสำหรับการนำเข้ารายการเดิมซ้ำเท่านั้น
- `date`: ปี ค.ศ. แบบ `YYYY-MM-DD` ไม่เกินวันนี้
- `kind`: `expense`, `income` หรือ `transfer`
- `account`: ชื่อบัญชีที่สร้างไว้ในผู้ใช้ปัจจุบัน บัญชีเหรียญ BTC/SOL ใช้กับรายการเงินสดไม่ได้
- `destination`: ชื่อบัญชีปลายทางสำหรับ `transfer`; รายรับ/รายจ่ายให้เว้นว่าง
- `amount`: จำนวนบวก ทศนิยมไม่เกินสองตำแหน่ง ไม่มีสัญลักษณ์เงินหรือ comma หลักพัน
- `currency`: ต้องตรงสกุลเงินสมุด เช่น `THB`
- `category`: รายจ่ายใช้ `food`, `snacks`, `rent`, `luxury`, `supplies`, `medical`, `other_expense`; รายรับใช้ `salary`, `freelance`, `interest`, `other_income`; โอนเงินให้เว้นว่าง
- `note`: รายละเอียด ใส่เครื่องหมายคำพูดครอบเมื่อมี comma/ขึ้นบรรทัดใหม่ และใช้ `""` แทนเครื่องหมายคำพูดในข้อความ

เลือก **เลือก CSV เพื่อนำเข้า** ตรวจทุกแถวแล้วกด **ยืนยันนำเข้าทั้งชุด** สูงสุด 1,000 รายการ / 4 MB ถ้าพบข้อผิดพลาดจะไม่บันทึกบางส่วน รหัสและข้อมูลเดิมที่ตรงกันจะไม่นับซ้ำ; รหัสเดิมที่มีข้อมูลต่างกันจะถูกปฏิเสธ

CSV นี้รองรับรายการรับ/จ่าย/โอนทั่วไป ไม่สร้างบัญชีให้อัตโนมัติ ไม่เดาภาษีหรือผูกบิลให้ และไม่ใช่ CSV ธนาคารหรือรายงานบัญชีคู่ที่แอปส่งออก

## CSV สำหรับ Excel

กด **ส่งออก CSV สำหรับ Excel** เลือกรายงานและภาษาไทย/อังกฤษ ไฟล์มี UTF-8 BOM เพื่อให้เปิดภาษาไทยใน Excel ได้ รายงานแยกเดบิตและเครดิตตามข้อมูลที่บันทึกแล้ว และป้องกันข้อความที่อาจถูก Excel ตีความเป็นสูตร

## สำรองและย้ายเครื่อง

1. Login เข้าผู้ใช้ที่ต้องการย้าย แล้วกด **ส่งออกไฟล์สำรอง .lbro**
2. Windows เลือกโฟลเดอร์บันทึก; Android เปิดหน้าต่างไฟล์ของระบบ เลือก Downloads หรือผู้ให้บริการไฟล์ที่ติดตั้งไว้
3. ส่งไฟล์ไปเครื่องใหม่ด้วยวิธีที่คุณเลือก
4. ติดตั้งแอปรุ่นเดียวกันหรือรุ่นที่รองรับไฟล์นี้ สร้างผู้ใช้ใหม่และตั้งรหัสผ่าน
5. เปิด **ตั้งค่า → ข้อมูล → เลือกไฟล์สำรองเพื่อกู้คืน** ตรวจจำนวนบัญชี/รายการ/บิล/ลูกหนี้และสกุลเงิน แล้วกดยืนยัน

ไฟล์รองรับสูงสุด 32 MB เก็บข้อมูลที่บันทึกแล้วของผู้ใช้ปัจจุบัน ได้แก่ บัญชี รายการและเดบิต/เครดิต รอบบัตร ประวัติชำระหนี้ บิลรายเดือน ลูกหนี้ รายละเอียดภาษีที่ผูกกับรายรับ จำนวนเหรียญ/ประวัติปรับพอร์ต แคชราคา และการตั้งค่า ไม่รวมผู้ใช้อื่นหรือรหัสผ่าน ไม่รวมโมเดล AI รูปใบเสร็จต้นฉบับ หรือแบบร่าง/worksheet ลดหย่อนภาษีที่ยังเป็นข้อมูลชั่วคราว

กู้คืนได้เฉพาะสมุดว่าง ข้อมูลที่มีอยู่จะไม่ถูกเขียนทับ ไม่มีการ merge ผู้ใช้หรือเดารายการซ้ำจากคนละสมุด ไฟล์ `.lbro` เป็นข้อมูลการเงินที่อ่านได้ ไม่ได้เข้ารหัส ควรเก็บไว้ในที่ส่วนตัว

ไฟล์มีชื่อรูปแบบและเวอร์ชันชัดเจน ระบบตรวจข้อมูลในฐานข้อมูลชั่วคราวที่ใช้ schema ของแอปเอง ไม่เรียกใช้ SQL/schema ที่แนบมาจากภายนอก แล้วบันทึกทั้งชุดใน transaction เดียว

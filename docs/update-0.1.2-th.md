# อัปเดตเป็น 0.1.2 โดยเก็บข้อมูลเดิม

ติดตั้งทับ 0.1.0 หรือ 0.1.1 โดยใช้ผู้ใช้ Windows หรือ Android package เดิม ไม่ต้องกรอกบัญชีใหม่ ตัวอัปเกรดเพิ่ม schema 10 เพื่อเก็บจำนวนเหรียญและแคชราคา ไม่ล้างบัญชี รายการ ภาษีที่ผูกกับรายรับ รอบบัตร หรือการตั้งค่า

## Windows

1. ปิดแอปก่อน
2. สำรองทั้งโฟลเดอร์ `%LOCALAPPDATA%\Dancing With My Code\Ledgers Bro\data` ขณะปิดแอป รวมไฟล์ฐานข้อมูลและไฟล์ `-wal` / `-shm` ถ้ามี
3. รัน `LedgersBro-0.1.2-windows-x64.msi` ใต้ผู้ใช้ Windows คนเดิม หรือแตก portable ZIP ทั้งโฟลเดอร์แล้วเปิด `ledgers-bro.exe`
4. เปิดแอป เลือกผู้ใช้ **Lookhin** แล้วตั้งชื่อ/รหัสผ่านครั้งแรก ตรวจบัญชีเดิม ข้อมูลจริงอยู่นอกโฟลเดอร์ติดตั้ง

MSI ใช้ UpgradeCode เดิม ถ้าเครื่องเคยลง preview ที่เลขรุ่นสูงกว่า 0.1.2 ตัวติดตั้งอาจปฏิเสธ downgrade อย่าลบโฟลเดอร์ข้อมูลเพื่อแก้ปัญหานี้

## Android

ใช้ ARM64 APK สำหรับมือถือที่รองรับ หรือ x86_64 APK สำหรับ emulator เดิม แอปทดสอบใช้ package `com.dancingwithmycode.ledgersbro.test` และลายเซ็นเดิม

- เปิด APK แล้วเลือก **Update / อัปเดต**
- ถ้าใช้ adb: `adb install -r LedgersBro-0.1.2-android-arm64-test.apk` หรือเลือกไฟล์ x86_64 ให้ตรง emulator
- **ห้าม uninstall, Clear storage หรือสร้าง emulator ใหม่แทนเครื่องเดิม** ถ้าต้องการเก็บฐานข้อมูลในเครื่องนั้น
- อย่าบังคับลงทับ APK คนละลายเซ็น ข้อความ signature mismatch ต้องแก้ที่ตัว APK

หลังเปิดรุ่นใหม่ เลือกผู้ใช้ **Lookhin** แล้วตั้งชื่อ/รหัสผ่านครั้งแรก ข้อมูลเดิมถูกผูกให้อัตโนมัติ แอปยังไม่มี Cloud sync แต่ส่งออกข้อมูลทั้งผู้ใช้เป็นไฟล์ `.lbro` ได้ที่ **ตั้งค่า → ข้อมูล** ดู [คู่มือนำเข้าและย้ายเครื่อง](data-transfer-th.md) และ [ระบบผู้ใช้](local-users-th.md)

## หลังอัปเกรด

พอร์ตคริปโตเดิมยังเป็นยอดที่เคยบันทึก ต้องกด **ระบุจำนวนเหรียญ** เองจึงเริ่มใช้มูลค่าตลาด ห้ามนำเงินบาทเดิมไปใส่ในช่อง BTC/SOL ดู [คู่มือพอร์ต](crypto-portfolios-th.md)

ฐานข้อมูล schema 10 เปิดด้วย 0.1.0/0.1.1 ไม่ได้ หากต้องย้อนรุ่นต้องใช้สำเนาก่อนอัปเดต ฟิลด์ลดหย่อนที่กรอกใน worksheet ภาษียังเป็นข้อมูลชั่วคราวต่อ session เช่นเดิม ส่วนข้อมูลภาษีที่ผูกกับรายรับที่บันทึกแล้วอยู่ในฐานข้อมูล

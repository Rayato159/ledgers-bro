# บันทึกด่วนด้วยเสียง — Android

สถานะ 21 กันยายน 2026: เพิ่มปุ่มไมค์และ adapter ถอดเสียงของ Android แบบ on-device แล้ว ใช้บริการเสียงของระบบ **ไม่ใช่ LLM และยังไม่ได้ฝัง Whisper หรือโมเดลเสียงไว้ใน APK** ความพร้อมภาษาไทยขึ้นกับบริการและโมเดลที่มีในเครื่อง Windows ยังไม่มี adapter เสียง ปุ่มจะแสดงว่าไม่พร้อม

## วิธีใช้

1. เปิด **บันทึกด่วน → พูดรายการ** ถ้ามีข้อความอยู่ ปุ่มชื่อ **พูดแทนข้อความ** ผลสำเร็จจะแทนข้อความเดิม; ยกเลิก/ฟังไม่ได้จะเก็บข้อความเดิม
2. แอปตรวจบริการและภาษาออฟไลน์ก่อน ถ้ายังไม่มีแต่ระบบรองรับ จะมีปุ่ม **ดาวน์โหลดภาษาไทยออฟไลน์** ใช้อินเทอร์เน็ตโหลดโมเดลครั้งแรกผ่านบริการของ Android ขนาดขึ้นกับบริการ ระบบอาจขอยืนยัน รอติดตั้งแล้วกดพูดอีกครั้ง แอปไม่เปิดไมค์เมื่อขอดาวน์โหลด
3. ถ้าภาษาพร้อมแล้ว แอปจึงขอสิทธิ์ไมโครโฟนจาก Android เมื่อผู้ใช้กดปุ่มพูดเอง
4. เริ่มพูดหลังขึ้น **กำลังฟัง** เช่น “กาแฟ 80” พูดทีละรายการ เว้นจังหวะหรือกด **พูดเสร็จแล้ว**
5. ตรวจข้อความ โดยเฉพาะเลข จำนวนสตางค์ และชื่อบัญชี แล้วกด **อ่านรายการ**
6. เลือกบัญชี/หมวด ตรวจรายละเอียด แล้วกด **ยืนยันบันทึก** เท่านั้นจึงเขียนสมุดบัญชี

ตัวอ่านคำสั่งยังเป็นกฎ deterministic: รองรับ `กาแฟ80`, `กาแฟ 80 บาท`, `กาแฟ80.50บาท` และตัวอย่างคำสั่งเดิม ไม่เดาคำอ่านตัวเลข เช่น `แปดสิบ` หรือคำแก้ความหมาย เช่น `80 ไม่ใช่ 800` ให้ผู้ใช้แก้เป็นตัวเลขและคำสั่งเดียวก่อน รูปแบบชื่อบัญชีที่มีช่องว่างยังต้องใช้เครื่องหมายคำพูดในคำสั่งเต็มหรือเลือกบัญชีจากฟอร์ม

## ความพร้อมของ Android

- การถอดเสียงนี้ต้อง Android 12 / API 31 ขึ้นไปและมีบริการ on-device ที่รองรับ ภาษาไทยใช้ `th-TH`; Android รุ่นเก่ากว่านี้ยังใช้ฟอร์มบัญชีได้
- API 33 ขึ้นไปตรวจ `installedOnDeviceLanguages` ก่อนเริ่มไมค์ แยกข้อความระหว่างยังไม่โหลด รอติดตั้ง ไม่รองรับภาษาไทย และตรวจความพร้อมไม่ได้
- API 31–32 ไม่มี API ตรวจรายชื่อภาษานี้ จึงลองกับ **on-device recognizer เท่านั้น** และคืนข้อผิดพลาดหากภาษาใช้ไม่ได้
- ถ้าระบบบอกยังไม่มีโมเดล ให้ตรวจการตั้งค่าภาษาออฟไลน์ของบริการเสียงที่ใช้ ตำแหน่งและภาษาที่ดาวน์โหลดได้ต่างกันตามผู้ผลิต ไม่ใช่ทุกเครื่องหรือทุก system image จะติดตั้งภาษาไทยได้
- emulator ที่มีบริการเสียงไม่ได้แปลว่ามีโมเดลไทยหรือรับเสียงจากไมค์คอมได้ การเปิดไมค์คอมเป็นการตั้งค่าอีกขั้น ไม่ได้เปิดให้อัตโนมัติ

ใช้ [`createOnDeviceSpeechRecognizer`](https://developer.android.com/reference/android/speech/SpeechRecognizer#createOnDeviceSpeechRecognizer(android.content.Context)) โดยตรง ห้ามเปลี่ยนเป็น recognizer ทั่วไปแล้วหวังพึ่ง [`EXTRA_PREFER_OFFLINE`](https://developer.android.com/reference/android/speech/RecognizerIntent#EXTRA_PREFER_OFFLINE) เพียงอย่างเดียว เพราะบริการอาจไม่ทำตาม flag นี้ การตรวจภาษาใช้ [`checkRecognitionSupport`](https://developer.android.com/reference/android/speech/SpeechRecognizer#checkRecognitionSupport(android.content.Intent,java.util.concurrent.Executor,android.speech.RecognitionSupportCallback))

## ขอบเขตและการแยกส่วน

- `crates/ui/src/voice.rs`: สถานะหน้าจอและอายุ session ผ่าน `UiGateway`; ผลสำเร็จเติมข้อความอย่างเดียว ไม่ส่ง Resolve/Preview/Commit อัตโนมัติ
- `apps/android/src/voice.rs`: JNI adapter และแปลงรหัสสถานะ/ข้อผิดพลาด ไม่รู้จักยอดหรือบัญชี
- `apps/android/native/MainActivity.kt`: class `OnDeviceVoiceInput` ดูแล permission, recognizer, timeout, cleanup บน Android main thread แยกจาก Activity และ CSV; อยู่ในไฟล์เดียวเพราะ Dioxus คัดลอก activity template นี้เข้า Gradle
- `crates/application/src/quick_entry.rs`: ตีความข้อความด้วยกฎและตรวจจำนวนเงินเต็มข้อความ ไม่ตัดท้ายที่ไม่รู้จักทิ้ง
- session ID กันผลลัพธ์ล่าช้าจากรอบที่ยกเลิก การออกจากหน้าทำให้ task ถูก drop และยกเลิก native capture; `onStop`/`onDestroy` ยกเลิกซ้ำอย่างปลอดภัย
- รอเตรียม/ขอสิทธิ์สูงสุด 45 วินาที ฟังสูงสุด 30 วินาที รอผลหลังพูดจบ 10 วินาที และ UI มีขอบเขตทั้งรอบ ผลที่ยาวเกิน 1,000 ตัวอักษรถูกปฏิเสธทั้งข้อความ ไม่ตัดยอดเงินทิ้ง
- แอปไม่เขียนไฟล์เสียง ไม่บันทึก transcript ลง log ไม่มี cloud ASR fallback และไม่ได้ขอสิทธิ์ไมค์ตอนเปิดแอป ข้อความเป็น draft ชั่วคราวในหน้า

## ตรวจบนเครื่องที่มีภาษาไทยก่อนปล่อยจริง

ใช้ข้อมูลทดลองและบัญชีแยก ห้ามถือว่าผ่านเพียงเพราะ APK build ได้:

- ตรวจสิทธิ์ครั้งแรก, ปฏิเสธ, ปฏิเสธถาวร, ถอนสิทธิ์, ปิดไมค์จาก privacy settings และกด retry
- เปิดโหมดเครื่องบินแล้วพูดไทยจริง: `กาแฟ 80`, `ข้าว 120.50`, ยอดคล้ายกัน 80/800, ชื่อบัญชีไทย, เสียงเบา/เสียงรบกวน ตรวจเลขในข้อความก่อนบันทึก
- เงียบ, พูดยาว, หยุดเอง, ยกเลิก, กดปุ่มซ้ำ, เปลี่ยนหน้า, เปิดฟอร์มอื่น, Home/ล็อกจอ, หมุนจอ, ปิดแอป ไฟแสดงไมค์ของระบบต้องหยุดและผลเก่าต้องไม่ทับข้อความใหม่
- ถอดเสียงสำเร็จแล้วยังไม่มีรายการบัญชีใหม่ กดอ่านและตรวจได้ แต่จนกว่าจะยืนยัน ยอดและจำนวนรายการต้องเท่าเดิม
- ทดสอบ ABI/เครื่องจริงหลายรุ่น ทั้งมี/ไม่มีโมเดลไทย และบริการที่ตรวจ support ไม่ได้; Windows ต้องแสดงไม่รองรับอย่างตรงไปตรงมา
- ก่อน Store release ต้องตรวจ privacy declaration/permission wording และพฤติกรรมบริการบนอุปกรณ์ที่รองรับอีกครั้ง

# อัปเดตเป็น 0.1.1 โดยเก็บข้อมูลเดิม

## Windows

ปิดแอป แล้วเปิด MSI 0.1.1 เพื่อติดตั้งทับ 0.1.0 โดยไม่ถอนการติดตั้งก่อน
ชื่อผลิตภัณฑ์, UpgradeCode และตำแหน่งข้อมูลยังเป็นค่าเดิม:
`%LOCALAPPDATA%\Dancing With My Code\Ledgers Bro\data\ledger.sqlite3`
MSI ลงโปรแกรมและ OCR แยกจากข้อมูลส่วนนี้ ไม่มีคำสั่งล้างสมุดบัญชี
ถ้าใช้ ZIP ให้แตกทั้งชุดไปโฟลเดอร์ใหม่ แล้วเปิดภายใต้ Windows user เดิม
ถ้าเคยใช้ `--data-dir` ต้องเปิดด้วยที่เก็บข้อมูลเดิมด้วย

สำรองโฟลเดอร์ข้อมูลหลังปิดแอปทุกหน้าต่างก่อนอัปเดต โดยรวมไฟล์ SQLite,
`-wal` และ `-shm` หากยังมีอยู่ ห้ามใช้ CSV แทน full backup

## Android

เปิด APK ใหม่แล้วเลือกอัปเดตแอปเดิม หรือใช้:

```powershell
adb install -r LedgersBro-0.1.1-android-arm64-test.apk
```

สำหรับ Emulator x86_64 เลือกไฟล์ `android-x86_64-test.apk`
application ID ยังเป็น `com.dancingwithmycode.ledgersbro.test` และต้องใช้ลายเซ็นเดียวกับ 0.1.0
versionCode เพิ่มจาก 1000 เป็น 1001 การติดตั้งอัปเดตเก็บ app data เดิมไว้

**อย่าถอนแอป อย่ากด Clear storage / ล้างข้อมูล และอย่าใช้ `adb uninstall`**
ข้อมูลอยู่ใน `no_backup/ledger.sqlite3` และแอปปิด Android Auto Backup ไว้
ถอนแอปหรือล้างข้อมูลจะลบสมุดในเครื่อง ถ้าระบบแจ้งลายเซ็นไม่ตรงให้หยุด
ตรวจว่าเลือก APK จาก release นี้ ไม่แก้ด้วยการถอนแอป

## การย้ายฐานข้อมูล

0.1.1 เพิ่ม schema 9 เพื่อเก็บข้อมูลภาษีที่ผูกกับรายรับ
การย้ายจาก schema 8 เปลี่ยนเฉพาะหมายเลขรุ่นของรูปแบบข้อมูล ไม่ลบหรือเขียนทับรายการเดิม
รายการเก่าที่ไม่มีข้อมูลภาษีจะยังไม่ถูกเลือกเข้าคำนวณโดยอัตโนมัติ
หลังอัปเกรดแล้ว 0.1.0 จะปฏิเสธการเปิดฐานข้อมูลใหม่ จึงควรเก็บ backup ก่อนอัปเดต

รายการ บัญชี รอบบัตร แผนรายเดือน และการตั้งค่ายังคงอยู่
ค่าที่กรอกเองในฟอร์ม worksheet ภาษี เช่น ค่าลดหย่อน ยังคงเป็นฟอร์มชั่วคราวตามพฤติกรรมเดิม
ส่วนประเภทเงินได้ ยอดก่อนหัก VAT และหัก ณ ที่จ่ายที่แนบกับรายการใหม่จะบันทึกลง SQLite

## สิ่งที่ทดสอบก่อนปล่อยรุ่นนี้

- ลง APK 0.1.0 แล้วอัปเดตทับด้วย 0.1.1 บน Emulator แยกสำหรับทดสอบ
  ตรวจว่าบัญชี 4 บัญชี รายการเดิม 5 รายการ รายการบัญชีคู่ 10 แถว
  รอบบัตร และการตั้งค่าตรงกันทุกแถวหลังย้าย schema 8 → 9
- ทดลองจ่ายบัตรบางส่วนผ่าน UI Android และตรวจว่าเงินสดกับหนี้ลดเท่ากัน
  โดยไม่เพิ่มรายจ่ายซ้ำ
- เปิด Windows executable รุ่น release ด้วยฐานข้อมูลจำลองเดิม
  กดใช้งานกราฟและชำระบัตรเต็มจำนวนได้ ตรวจปุ่มบัตรที่วางเรียงกันให้เท่ากัน
- ตรวจ MSI ว่าใช้ UpgradeCode เดิม และ APK ทั้งสองสถาปัตยกรรมมีลายเซ็นเดิม

ทั้งหมดใช้ข้อมูลจำลอง ไม่แตะสมุดจริง การติดตั้ง MSI ทับบน Windows เครื่องจริง
และการอัปเดตบนโทรศัพท์ Android จริงยังไม่ได้ทดสอบในรอบนี้

# บัตรเครดิตและภาพรวมหนี้

บัญชีบัตรเครดิตใหม่ต้องระบุ **วันตัดรอบบิล** และ **วันครบกำหนดชำระ** (1–31)
ผ่านฟอร์มเพิ่มบัญชีหรือช่องตรวจ prompt ตัวอย่าง:

```text
เพิ่มบัญชี ชื่อ Visa ประเภท บัตรเครดิต ยอดหนี้ 0 วันตัดรอบ 20 วันชำระ 5
```

รายการวันที่ 20 รวมในรอบที่ตัดวันที่ 20 รายการวันที่ 21 เป็นรอบเดือนถัดไป
วันชำระต้องอยู่หลังวันตัดรอบ ถ้าวันที่ที่ตั้งไว้ไม่หลังวันตัดรอบจริง จะใช้เดือนถัดไป
วันที่ไม่มีในเดือนนั้นจะใช้วันสุดท้าย รวมถึงกุมภาพันธ์และปีอธิกสุรทิน
ระบบใช้วันที่รายการที่ผู้ใช้กรอก จึงควรเทียบกับวันที่ลงบัญชีในใบแจ้งยอดธนาคาร

## เส้นทางเงิน

- รูดบัตร: เพิ่มรายจ่ายตามหมวดและเพิ่มหนี้บัตร เงินในบัญชีธนาคารยังไม่เปลี่ยน
- หน้า **หนี้และบิล** หรือ **บัญชี**: แสดงยอดคงค้างแยกรอบที่ตัดบิลแล้ว/ยังไม่ตัดบิล/เลยกำหนด
- กด **ชำระบัตรจากบัญชี**: เปิดรายการโอนที่ใส่บัตรปลายทางไว้แล้ว เลือกบัญชีต้นทาง
  แก้จำนวนเงินหากจ่ายบางส่วน และตรวจยืนยันก่อนบันทึก
- ชำระบัตร: ลดเงินในบัญชีต้นทางและลดหนี้พร้อมกัน ไม่สร้างรายจ่ายซ้ำ
  กระจายยอดลดหนี้ไปยังรายการเก่าก่อน หากจ่ายเกินจะแสดงเป็นเครดิตคงเหลือและสินทรัพย์
- ยกเลิกรายการ: ใช้ reversal เดิมของบัญชีคู่ รายงานหนี้คำนวณใหม่จาก journal เดียวกัน
- รายจ่ายประจำที่ลงบัตร: งวดนั้นขึ้นว่าบันทึกลงบัตรแล้ว ไม่ค้างในแผนซ้ำ
  แต่ยังค้างชำระในบัญชีบัตรจนกว่าจะมีรายการโอนจ่ายคืน

## ภาพรวม

กราฟเปรียบเทียบแยกช่วงเวลาให้ชัดเจน:

| ตัวเลข | ความหมาย |
| --- | --- |
| สินทรัพย์ปัจจุบัน | ยอดบัญชีบวกและเงินต้นลูกหนี้คงค้าง ณ วันนี้ ลูกหนี้ยังไม่ใช่เงินสด |
| จ่ายเงินจริงเดือนนี้ | รายจ่ายจากบัญชีที่ไม่ใช่บัตร + โอนจากบัญชีที่ไม่ใช่บัตรเพื่อชำระบัตรในเดือนปัจจุบัน |
| หนี้คงค้างรอชำระ | ยอดบัญชีติดลบ ณ วันนี้ รวมทั้งบัญชีบัตรเครดิต |
| แผนเดือนนี้ที่ยังไม่บันทึกจ่าย | รายจ่ายประจำเดือนปัจจุบันที่ยังไม่ผูกกับรายการจริง ยังไม่ลงเป็นหนี้ใน journal |
| สินทรัพย์สุทธิ | สินทรัพย์ปัจจุบัน − หนี้คงค้าง |

ยอดที่จ่ายจริงได้ลดบัญชีไปแล้ว ไม่หักซ้ำจากสินทรัพย์ปัจจุบัน กราฟทั้งสี่แท่งเป็นการเปรียบเทียบ
ไม่ใช่องค์ประกอบที่จะบวกรวมกันเป็นสินทรัพย์ ค่าให้ยืมเงินต้น/โอนระหว่างบัญชีสินทรัพย์
ไม่รวมในตัวชี้วัดจ่ายเงินจริงนี้ และรายรับลบรายจ่ายที่บันทึกยังแสดงแยกจากเงินจ่ายจริง

## ข้อมูลเดิมและขอบเขต

Schema 8 เพิ่มรอบบัตรในตารางบัญชีโดยไม่แก้ยอดเงินหรือ journal เก่า
บัตรเดิมที่ไม่มีเงื่อนไขขึ้นฟอร์มให้เติมครั้งแรก ข้อมูลที่ตั้งแล้วไม่เปิดให้เปลี่ยนย้อนหลัง
เพราะจะเลื่อนรอบของรายการเดิม ยอดเปิดบัญชีแสดงเป็นยอดยกมาที่ไม่ทราบรอบ จึงไม่เดาว่าเลยกำหนด
แอปรุ่นก่อน schema 8 จะไม่สามารถเปิดฐานข้อมูลที่อัปเกรดแล้ว ให้สำรองข้อมูลก่อนเปลี่ยนรุ่น

นี่เป็นตัวติดตามจากข้อมูลที่บันทึก ไม่เชื่อมบัญชีธนาคาร ไม่คำนวณดอกเบี้ยบัตร ค่าปรับ
วันหยุดธนาคาร ยอดขั้นต่ำ หรือแผนผ่อนเฉพาะธนาคาร ตัวเลขวันที่ควรเทียบใบแจ้งยอดจริง

## การแยกชั้นและทดสอบ

- `CreditCardCycle` เป็น value object ใน domain; `Account` เป็น entity ที่ถือเงื่อนไข
- Application สร้างรายงานรอบบัตรและตัวชี้วัดเงินจ่ายจริงจาก journal โดยใช้จำนวนเต็มหน่วยย่อย
- SQLite รับผิดชอบ migration/การบันทึกเงื่อนไขแบบ atomic และตรวจข้อมูลเก่าก่อนเปลี่ยน
- UI ใช้เปอร์เซ็นต์เฉพาะวาดกราฟ ไม่คำนวณหรือแก้ยอดเงินจริง

ทดสอบใน `crates/domain/src/credit.rs`, `crates/infrastructure/tests/credit_cycles.rs`
และ `crates/infrastructure/tests/prompts.rs`: วันก่อน/ตรง/หลังตัดรอบ ข้ามปี ทุกคู่วัน 1–31
ในเดือนสั้น/ปีอธิกสุรทิน บัตรที่ไม่ระบุวัน จ่ายบางส่วน/เกินยอด reversal การจ่ายแผนด้วยบัตร
เก็บเงื่อนไขหลังเปิดใหม่ migration และสร้างผ่าน prompt ก่อน atomic commit

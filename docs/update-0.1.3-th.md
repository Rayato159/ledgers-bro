# อัปเดตเป็น 0.1.3

รุ่นนี้เพิ่ม **จดจำฉัน 7 วัน** และแก้แนวหัวข้อ Settings ให้ตรงกับแท็บและเนื้อหา

- Windows: ติดตั้ง MSI ทับ หรือใช้ portable ZIP ทั้งโฟลเดอร์ภายใต้ผู้ใช้ Windows เดิม ข้อมูลอยู่ในโฟลเดอร์ข้อมูลแอป ไม่ใช่โฟลเดอร์ติดตั้ง
- Android: ใช้ APK สำหรับสถาปัตยกรรมเดิมและติดตั้งทับ อย่าถอนติดตั้งหรือกดล้างข้อมูล รุ่นมือถือทั่วไปใช้ ARM64; Emulator x86_64 ใช้ไฟล์ x86_64
- ชื่อผู้ใช้ รหัสผ่าน บัญชี และรายการเดิมยังอยู่ ไม่ต้องตั้งผู้ใช้ใหม่เมื่อต่อจาก 0.1.2
- เลือก “จดจำฉัน 7 วัน” ตอน Login เพื่อเข้าอัตโนมัติเมื่อเปิดแอปครั้งต่อไป ออกจากระบบหรือเปลี่ยนรหัสผ่านเพื่อยกเลิก เลือกจดจำเฉพาะเครื่องส่วนตัว

ฐานสมุดบัญชียังใช้ schema 10 ส่วนฐานผู้ใช้อัปเกรดจาก 1 เป็น 2 เพื่อเก็บสิทธิ์ Login ที่จดจำไว้ รุ่น 0.1.2 จะไม่เปิดฐานผู้ใช้รุ่นใหม่นี้ ให้เก็บสำเนาโฟลเดอร์ข้อมูลก่อนอัปเดตหากต้องการย้อนรุ่น โดยปิดแอปก่อนคัดลอก

ไฟล์ `.lbro` เก็บข้อมูลสมุดบัญชี ไม่รวมรหัสผ่านและสิทธิ์ Remember me ดู [ระบบผู้ใช้](local-users-th.md) และ [คู่มือย้ายเครื่อง](data-transfer-th.md)

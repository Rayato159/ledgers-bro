# Update to 0.1.11

The Accounts page now opens with **All accounts**, showing cash, bank, credit-card, investment and crypto accounts together. The existing category tabs and card billing view remain available.

Three summary cards show account assets, account liabilities and the net account total. Credit-card overpayments count as assets. Crypto holdings use the same market valuation as Overview; portfolios without prices are explicitly flagged. Receivables and unpaid recurring plans are excluded from account totals.

The layout adapts to desktop and narrow screens and supports Thai and English. This release does not change saved data or the database schema.

Install the Windows MSI or portable ZIP, or the Android test APK for your architecture, over the existing installation. Do not uninstall or clear storage. Installed data and models are retained. Personal data, test profiles, model weights and signing credentials are excluded from release packages.

See BUILDINFO.txt for verification and platform limits and SHA256SUMS.txt for download checksums.

# Tanuki salaryman

The active Ledgers Bro mascot is an adult tanuki in an oversized Japanese office suit. His tired eyes, crooked smile and cigarette give him a cheeky, world-weary personality.

Lookhin supplied his original drawings as style references. The selected artwork was generated with the built-in image generation tool: imperfect dark ink, muted colors, cel-shaded clothing and restrained grain. The reference drawings are not redistributed here.

- `masters/hero.png`: full-body mascot, used in existing illustration and empty-state areas.
- `masters/logo.png`: compact head-and-collar mark, used in navigation and launcher icons.
- [Prompts](prompts.md): generation and refinement instructions.

Masters are retained unchanged with their generated alpha. `python scripts/prepare-art-assets.py` produces runtime PNGs and Windows/Android icon exports. The old crab assets are retired; Git history preserves them. Do not reintroduce decorative figures beside action buttons or removed promotional banners.

# Studio mascot

The active mascot is an original adult male creative with messy dark hair, black glasses, an oversized teal jacket, headphones and a coral pocket notebook. Thin ink contours, restrained flat shading and warm neutral colors follow the visual direction supplied by Lookhin.

The selected full-body character and compact face mark were generated with the built-in image generation tool. External style references are not redistributed. See the [generation prompts](prompts.md).

- `masters/hero.png`: original selected transparent full-body illustration.
- `masters/logo.png`: original selected transparent compact face mark.
- `../../crates/ui/assets/studio/`: mechanically resized runtime exports.
- [App icons](../app-icon/README.md): Windows and Android exports.

Keep the masters unchanged. Run `python scripts/prepare-art-assets.py` to reproduce exports. The Studio theme uses warm paper, muted teal and coral; existing saved theme preferences remain intact. Earlier mascot concepts remain available through Git history.
